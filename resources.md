# Learning resources

Every course here was checked for rating and review count in October 2026. Ratings change, so look again before you buy. Udemy runs sales most weeks; don't pay full price.

## If you can't code yet (do this first, 2 to 3 weeks)

| Resource | Rating | Length | Why |
| --- | --- | --- | --- |
| [Programming with Python: HandsOn Introduction for Beginners](https://www.udemy.com/course/python-programming-beginners) (Febin George) | 4.6 from about 12,600 ratings | About 3.5 hours | Built for people who have never coded. Short on purpose |
| [Learn Playwright with Python (Web & API Automation)](https://www.udemy.com/course/learn-playwright-with-python-web-api-automation/) (Pavan Kumar) | 4.7 from about 690 ratings | | Python basics again, then pytest, Playwright UI and API testing. Matches week 6 |

You only need enough Python to read and edit the files in this repo. You can use an AI coding assistant to explain any line you don't understand.
